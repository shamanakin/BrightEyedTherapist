How to Use Life Map

Start here

  1. Put your client's name or initials at the top of the sidebar.
  2. Add events with the colored buttons — you can drag them on the timeline afterward.
  3. Click any event to add details — body sensations, cognitions, SUDS — or to mark it as a target.
  4. Export JSON before you close: your map lives in this tab only until you save it.

Event types

Trauma (red)Single events, or Duration for sustained periods
Positive (green)Strengths, wins, supports
Resource (amber)Safe places, anchors, people
Neutral (gray)Context that helps the story read

Targets & the queue

Open a trauma event and check Processing Target — it gets a dashed border on the timeline.
Marked targets appear in the Processing Queue in the sidebar, ready for EMDR or session logging.
Use Process Next to jump to the next target in line.
